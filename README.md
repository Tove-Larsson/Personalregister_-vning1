# Personalregister

## Uppgift

Skapa ett enkelt personalregister i C# för en restaurangverksamhet.

### Krav

* Kunna registrera anställda med namn och lön.
* Lagra anställda under programmets körning.
* Kunna visa registrerade anställda i konsolen.

## Extra

Utöver kraven har jag lagt till:

* Meny för att navigera i programmet.
* Validering av namn och lön.
* Riktigt basic Enhetstester med xUnit.
